Connect your Arduino

Enter the board's local IP address to try the /status endpoint. Example: 192.168.1.50.

Heads up: GitHub Pages is HTTPS, while a basic UNO R4 WiFi web server is usually HTTP. Browsers can block that cross-origin/insecure connection. For a reliable live demo, open the dashboard served directly by the Arduino on the same Wi-Fi network, or add a secure HTTPS bridge. This GitHub page works as the project showcase/demo.
